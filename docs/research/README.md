# Market research

Written and kept current by the `market-research` agent
(`.claude/agents/market-research.md`). Run it with `/market-research` in Claude
Code:

- `/market-research competitors`: who else helps creators get found by brands
- `/market-research demand`: what creators, SMMs and brands say they need
- `/market-research deep-dive <name or question>`: one company or one question

| File                     | What it is                                              |
| ------------------------ | ------------------------------------------------------- |
| `COMPETITORS.md`         | Living competitor tracker, updated in place each run    |
| `DEMAND-SIGNALS.md`      | Living log of public demand signals, newest first       |
| `YYYY-MM-DD-<mode>*.md`  | One brief per run: the answer, findings, so-what, gaps  |

Every claim links to its source with the date it was read. Real users'
words live in `docs/CUSTOMER-VOICE.md`, which outranks anything here.
