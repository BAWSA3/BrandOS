# Part 1: The bible

## The world in one paragraph

BrandOS is the institution that keeps the record of creator reputation. Restaurants have the
Michelin Guide, films have the Criterion Collection, colour has Pantone. Creators have had
follower counts. BrandOS **reads** a creator's brand from their real posts, **classifies** it,
**enters** them into the Index with a permanent number, **certifies** what can be proven, and
**records** what they deliver. The record is curated by an editor, Bawsa, and kept with the
care of an archive: dated, numbered, exact, and beautiful enough to want to be in.

## The belief

> **Reputation should be a record, not a rumour.**

Line for the world: **"Reputation on the record."** Official form, no comma (decided Oct 23).
Two-line lockup for big type: **Reputation** / **on the record.**

## Three pillars (every decision should serve at least one)

| Pillar          | Means                                                                                    | Shows up as                                                |
| --------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| **The Record**  | Permanent, numbered, dated, honest. Nothing is hidden, bad marks included (with context) | Entry numbers, the Index, receipts, certificates           |
| **The Reading** | Precise and evidence-based: read from real posts, never self-reported                    | The score, classifications, the machine layer (VCR, codes) |
| **Taste**       | Curated, restrained, editorial. Quality you can feel in every pixel                      | The editor, issues, materials, motion, the printed Index   |

## The institution's principles (its "Michelin rules")

1. **Standing can't be bought.** Pro buys visibility (Featured) and tools. It never buys a
   score, a classification, Verified or Standing. Paid placement is always labelled.
2. **The record is honest.** What's shown is real; estimates are labelled as estimates.
3. **Membership is chosen.** Nobody is in the Index who didn't ask to be.
4. **The same reading for everyone.** One method, published, applied the same to every entry.
5. **Restraint.** If it doesn't serve the record, the reading or the taste, it isn't added.

| Role                 | Who                          | Notes                                                                                 |
| -------------------- | ---------------------------- | ------------------------------------------------------------------------------------- |
| **The institution**  | BrandOS                      | Speaks in the formal voice. Never "I"                                                 |

## The classifications

The eight archetypes become the institution's official classification system: each has a
class number, a code (the name we already use) and a definition. Written like a catalogue
entry: `CLASS 03 · BUILD.EXE`.

| Class | Code      | Definition (from the reading engine) |
| ----- | --------- | ------------------------------------ |
| 01    | SOURCE    | Knowledge authority                  |
| 02    | FORESIGHT | Shapes the narrative                 |
| 03    | BUILD.EXE | Builder. Shipper. Doer               |
| 04    | ARC       | Rising star. Growth story            |
| 05    | RELAY     | Super connector                      |
| 06    | FREQ      | Entertainer. Community builder       |
| 07    | ENTROPY   | Risk-taker. Cult builder             |
| 08    | NULL      | Ideas over identity                  |

Legacy names in old scans (`SIGNAL_SAGE`, `The Prophet`…) map onto these through
`normalizeArchetypeName`; anything that doesn't is shown as "Unclassified".

## Standing (what XP becomes)

Standing accrues from showing up: consistent posting, check-ins, receipts filed and confirmed,
time in the Index. The points stay private; the **rank** is part of the record.

| Rank | Name              | Roughly                                                 |
| ---- | ----------------- | ------------------------------------------------------- |
| I    | **Entered**       | In the Index                                            |
| II   | **Noted**         | Consistent for 30 days                                  |
| III  | **Established**   | 90 days, or a confirmed receipt                         |
| IV   | **Distinguished** | Several confirmed receipts, Verified                    |
| V    | **Canon**         | The top of the record; very few, reviewed by the editor |

Rank thresholds get tuned on real data after launch; the names are what matter now.

| Founding Member          | early adopter, OG           |                                                   |

**Never:** "influencer", "unlock", "level up", "hack", "10x", "AI-powered", "game-changer",
"grow your followers", emoji in the institution's voice, exclamation marks in the

**The two voices, side by side:**

| Moment      | Institution (product, record, certificates)             | Bawsa (X, emails, Reading Room)                        |
| ----------- | ------------------------------------------------------- | ------------------------------------------------------ |
| Joining     | "Entry No. 0042. Entered 2 Nov 2026."                   | "you're No. 0042. welcome in."                         |

Institution style: sentence case for body, VCR caps for labels, short declaratives, dates

# Part 3: The UX/UI and aesthetic system

## Principles

1. **Every screen is a document.** Pages read like pages from the record: dated, numbered,
   framed, with metadata in the margins.
2. **One ink.** Klein #0047FF is the institution's ink: numbers, stamps, the verified mark,
   the one action that matters. Never decoration.
3. **The machine shows only while it reads.** VCR labels and code are the reading engine's
   handwriting; the rest is editorial.
4. **Motion is a stamp, not a bounce.** Things arrive by being pressed, typed, ruled or
   counted. Hard cuts, no fades between scenes.
5. **Restraint is the luxury.** Huge type, lots of space, few elements, perfect alignment.

## Materials

| Material            | Digital form                                                   | Use                                           |
| ------------------- | -------------------------------------------------------------- | --------------------------------------------- |
| **Bone paper**      | `#F2EFE8` canvas + film grain (sigma ~4, the "tooth")          | Default ground everywhere                     |
| **Night stock**     | `#0E0E0E` ground, Bone text                                    | The Night finish; after-hours, ceremonies     |
| **Klein ink**       | `#0047FF`, flat, never gradient                                | The signal: numbers, stamps, ✓                |
| **Hairline ruling** | 1px rules at 35% ink, 72px margins                             | The document frame (as in The Check)          |
| **The stamp**       | Klein disc, soft inner press (subtle inner shadow), white mark | Verified, entry confirmed                     |
| **Embossing**       | Very low contrast raised type on cards                         | Member card numbers, certificates             |
| **Perforation**     | Dotted rule                                                    | Tear-off edge on the member card and receipts |

## Type

| Role                     | Face                                                       | Rules                                           |
| ------------------------ | ---------------------------------------------------------- | ----------------------------------------------- |
| Display                  | Helvetica (Inter Tight on dashboard, `/@handle`, MCP card) | Huge, tight tracking, sentence case             |
| Labels / catalogue codes | VCR OSD Mono                                               | Caps, wide tracking, small. The machine's voice |
| Data                     | JetBrains Mono                                             | Tabular numerals; `No. 0042`, dates, scores     |
| Body                     | Helvetica / Inter                                          | 16px+, generous line height                     |

Numbers: `No. 0042` (4 digits), `Nº 001` for issues, scores as `76` with `/100` in a label.
The `Nº` glyph is in VCR; `·` is not (use `/` in VCR).

## Layout

- **The document frame:** top and bottom hairline rules at 72px; corner metadata
  (`BRANDOS` · section · `ENTRY No. 0042` · date).
- **The catalogue grid** for the Index: cards like catalogue plates, number top-left,
  classification as a code.
- **Editorial asymmetry** on member pages: big number or name left, metadata column right.
- **One action per screen**, in Klein.

## Motion vocabulary

| Name                  | What it does                                                    | Timing                  |
| --------------------- | --------------------------------------------------------------- | ----------------------- |
| **Press** (the stamp) | Scale 112% → 100%, soft ring outward, no overshoot              | 420ms, ease-out         |
| **Entry**             | Text types in (VCR, monospace, width held so nothing shifts)    | ~30ms per character     |
| **Rule**              | Hairlines draw on from the left                                 | 900–1300ms, ease-in-out |
| **Count**             | Numbers count up (Motion+ AnimateNumber)                        | 700–2000ms, ease-out    |
| **Cut**               | Hard cut between scenes; no crossfades                          | Instant                 |
| **Settle**            | Small elements arrive by position or scale, never opacity alone | 200–450ms               |

One headline moment per screen, aimed at the Klein signal (unchanged Motion+ rule).
Reduced-motion: everything resolves to its final state instantly.

## Sound vocabulary (off by default, one toggle)

| Sound     | When                                | Character                               |
| --------- | ----------------------------------- | --------------------------------------- |
| **Press** | Verified, entry confirmed           | A low, soft hit with a short paper tail |
| **Type**  | Labels typing during a reading      | A dry, quiet tap, randomized slightly   |
| **Cut**   | Scene changes in films and reveals  | A soft tap                              |
| **File**  | A receipt filed / Standing advanced | A short two-tone chime, warm            |

# Direction 02: the field (decided Oct 23)

From Bawsa's references (dithered photographs, a grid with one hot cell, metadata strips, CRT
glow). Prototype: the "BrandOS World" artifact, Direction 02 section.

| Decision             |                                                                                                                             |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **World surfaces**   | Klein field + 1-bit dither: homepage hero, the Index, member cards, the claim moment, share images, film                    |
| **Reading surfaces** | Stay on bone: your record (dashboard), pricing, settings, long text, email bodies                                           |
| **Signal colour**    | **Coral `#FF4B2B`**, used only for "this one": your entry, the selected cell, the live state                                |
| **Dithered imagery** | Members' own photos · nature (clouds, sky, water; procedural, no image rights) · product moments (scores, numbers, screens) |
| **Type**             | Helvetica/Inter Tight + VCR stay; **IBM Plex Mono** added for metadata strips and lowercase lines                           |

**Rules of the field**

1. The dither is 1-bit: white dots on Klein (8×8 Bayer), with a faint glow. No greys, no gradients.
2. The grid is white, 1px, over the image. **One coral cell per screen, maximum.**
3. Coral is a fill, never text on Klein (contrast). White text on the field; ink text on bone.
4. Motion on the field follows the vocabulary: press, type, rule, count, cut. The field itself is still
   (no drifting clouds behind reading text); the metadata strip may run slowly.
5. Every field has a static poster first (no blank flash, no layout shift), then the canvas.

# Direction 03: the system (decided Oct 23)

The field from the "Reputation on the record." video becomes the background of BrandOS,
small things to big.

| Decision         |                                                                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Background**   | **The field, everywhere**: Klein, procedural clouds as a 1-bit dither, the white grid, one coral cell, the Plex Mono metadata strip. Exactly the loop video's look |
| **Long reading** | Dashboards, pricing details and long text sit on **bone panels placed on the field**, so they stay readable                                                        |
| **Glows**        | **None.** Flat Klein, 1-bit dots, grid, one coral cell                                                                                                             |
| **Clouds**       | Only the dithered field clouds. **No pixel-art cloud illustrations** (the Higgsfield library in `marketing/pixel-clouds/` is shelved)                              |
| **Palette**      | Klein (ground), white (dots, grid, type on the field), Bone + Ink (panels), Coral (one cell, "this one")                                                           |
| **How deep**     | Components (buttons, inputs, cards, tags, toasts, modals) · charts and data in dots · icons, cursor and transitions (dither wipes)                                 |
| **Timing**       | Before Nov 2: tokens, components, homepage, scan, the Index and claim, pricing. After: charts, icons, cursor, transitions and the dashboard, in weekly drops       |

Supersedes Direction 02's "world surfaces blue, reading surfaces bone" split: the field is the
ground everywhere; bone is a panel material, not a page background.
