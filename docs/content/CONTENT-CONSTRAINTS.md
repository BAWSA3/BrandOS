## Claims I won't make

No inventing metrics. No hypothetical case studies. No "imagine if…"
framed as reality.

- Don't invent user quotes — only use ones in BrandOS HQ CUSTOMER-VOICE.md
- Don't project future revenue as if it's happened

## Why these rules exist

Every rule here is either:
1. **Positioning** — violating it makes me look like a generic guru
2. **Honesty** — violating it erodes trust I need for the April goal
3. **Voice** — violating it sounds like someone else

If a rule stops making sense, delete it — but add a DECISION entry
explaining why.
